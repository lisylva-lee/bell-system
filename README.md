# 🔔 智能打铃系统 BellSystem

> Windows 7/10/11 通用的本地定时打铃软件 — 不依赖服务器、不依赖网络，绿色免安装。

**GitHub 仓库**: https://github.com/lisylva-lee/bell-system
（push 到 `main` 分支自动触发 Actions 双架构编译，产物在 Actions Artifacts 下载）

## 项目结构

```
BellSystem/
├── bell_system.py          ← 入口（薄壳，兼容旧 import）
├── web_server.py           ← 兼容壳（实现已移到 bellapp/web/api.py）
├── bellapp/                ← 应用实现（v2.3 起分层）
│   ├── paths.py            ← 路径解析（只读介质自动回退 %APPDATA%）
│   ├── settings.py         ← 设置读写（只增键，旧配置无需改动）
│   ├── logsetup.py         ← 日志（按天轮转，保留 30 天）
│   ├── storage.py          ← SQLite（user_version 迁移 + 每线程连接 + 日志清理）
│   ├── player.py           ← 播放引擎（代际号取消 + 转码缓存）
│   ├── scheduler.py        ← 调度引擎（绝对时间轮询 + 日历感知）
│   ├── csvio.py            ← 课表 CSV 导入导出
│   ├── power.py            ← 开机自启 / 防休眠（SetThreadExecutionState）
│   ├── app.py              ← 装配入口与退出清理
│   ├── ui/                 ← main_window.py（主窗口）/ dialogs.py（各对话框）
│   └── web/                ← api.py（HTTP 接口与鉴权）/ ui.py（内嵌网页）
├── tests/                  ← pytest 用例（也可 python tests/run_all.py）
├── requirements.txt        ← 运行期依赖（锁版本）
├── requirements-dev.txt    ← 开发/CI 依赖（含 pytest、pyinstaller）
├── bell.ico                ← 程序图标
├── .github/workflows/      ← CI：先跑测试，再编译 x86/x64
│
├── data/                   ← SQLite 数据库（自动创建，与 exe 同目录）
│   └── bell.db
├── logs/                   ← 运行日志（自动创建，按天轮转）
├── config/                 ← 配置文件（自动创建）
└── ffmpeg/                 ← 可选：放 ffmpeg.exe 支持更多音频格式
```

## 功能

| 功能 | 说明 |
|------|------|
| **定时方式** | 每天 / 每周(选星期) / 指定日期 / 一次性 |
| **音频格式** | MP3, WAV, M4A, AAC, OGG, FLAC |
| **铃声方案** | 多套方案一键切换（学校工作日 / 工厂 / 自定义） |
| **系统托盘** | 右下角托盘运行，右键菜单快速操作 |
| **执行日志** | 每次打铃自动记录成功/失败原因 |
| **主界面** | 当前时间、精确倒计时（今天/明天/日期+星期）、任务列表 |
| **开机自启** | 设置中可启用（注册表） |
| **防止休眠** | 设置中可启用（电源策略） |
| **绿色免安装** | 解压即用，数据持久化在 exe 同目录 |
| **🌐 Web 远程控制** | 局域网内手机/电脑浏览器远程管理：任务增删改查、立即打铃、暂停、切换方案、查看日志（v2.0） |
| **🛡 暂停/漏打留痕** | 暂停期间到点、或系统睡眠导致漏打，都会在执行日志里留记录（v2.1） |
| **📅 节假日/调休日历** | 放假全天不打铃；调休补课日可按「周几的课表」打铃（v2.2） |
| **📥 课表导入/导出** | CSV 批量建任务、导出备份，Excel 直接打开（v2.2） |
| **🔎 搜索/排序/今日预览** | 任务多也能快速定位，主界面显示今日剩余计划（v2.2） |
| **⚠ 失败告警** | 打铃失败/漏打弹托盘气泡，网页控制台顶部红色横幅（v2.2） |
| **🔒 Web 安全加固** | 令牌仅走请求头、防跨站请求、铃声路径白名单、失败限速（v2.1） |

## 使用方法

1. 双击 `BellSystem.exe` 运行
2. 点击 **添加任务** 设置打铃规则（任务名、重复方式、时间、铃声、音量）
3. 关闭窗口自动最小化到系统托盘，到点自动打铃
   - 放假/调休：点「📅 日历」把放假日设为「放假」，调休补课日设为「上课」并选「按星期几的课表」
   - 批量建任务：点「📥 课表导入/导出」，先导出一份当模板，改好再导入
4. **远程控制**：系统设置 → 勾选「启用局域网网页远程控制」→ 手机浏览器打开主界面底部状态栏显示的地址即可管理。
   **强烈建议同时设置「访问令牌」**：不设令牌时，同一局域网内任何设备都能打开网页操作打铃（状态栏与网页顶部会持续提示风险）。

## 编译说明

### GitHub Actions（推荐）

push 到 `main` 自动编译 x86/x64 两个版本，产物在仓库 Actions 页面的 Artifacts：

```yaml
# .github/workflows/build.yml 核心（v2.3：先测后编，依赖锁版本）
test:
  - uses: actions/setup-python@v5
    with: {python-version: '3.8.10'}
  - run: pip install -r requirements-dev.txt
  - run: pytest tests -q
build:
  needs: test
  strategy: {matrix: {arch: [x86, x64]}}
  - run: pyinstaller --onefile --windowed --icon=bell.ico --name=BellSystem bell_system.py
```

### 本地编译

```bash
pip install -r requirements-dev.txt
python tests/run_all.py          # 或 pytest tests -q
pyinstaller --onefile --windowed --icon=bell.ico --name="BellSystem" \
  --hidden-import=pygame --hidden-import=pystray --hidden-import=PIL bell_system.py
```

> ⚠️ 注意：编译 32 位版必须使用 32 位 Python。
> Win11 上无法安装 Python 3.8.10（WiX 安装器 1603 bug），建议直接用 GitHub Actions 编译。

## 安全说明（V2.1）

Web 远程控制默认绑定 `0.0.0.0`，属于**局域网内可访问**的服务：

- **务必设置访问令牌**。不设令牌时，同一局域网内任何设备都能打开网页增删打铃任务、立即打铃；
  程序会在状态栏、网页顶部和启动提示里三处告警，但不会强制阻止（尊重使用场景）。
- 令牌只通过 `X-Auth-Token` 请求头传递，不会出现在 URL、浏览器历史或代理日志中；
  连续 5 次输错会被临时限速。
- 服务端只接受 `application/json` 请求，并校验 `Origin`，因此外部网页无法跨站触发打铃。
- 铃声路径仅允许服务器本机的音频文件（`.mp3/.wav/.m4a/.aac/.ogg/.flac`），拒绝网络路径。
- 本服务**不提供 HTTPS**，令牌以明文在局域网内传输；如需跨不可信网络使用，请自行套一层反向代理（如 nginx + TLS）。
